# Retros

Day-by-day SPY/TLT paths after FOMC decision days, sliced by decision-day color and
stated regime. Generated by `scripts/retro_color_regime.py`; regenerate any slice with
`uv run python scripts/retro_color_regime.py --regime <Tightening|Easing> --color <Green|Orange|Blue|Red> --horizon <N>`.

| File | What |
|---|---|
| `retro_blue_tightening_5d.csv` | Long format, one row per event x asset x day: `decision, chair, action, ff_target, asset, day, close, daily_pct, cum_from_d0_pct`. Day 0 is the decision day's own move; `cum_from_d0_pct` is cumulative from the day-0 close (blank on day 0). Built for charting. |
| `retro_blue_tightening_5d.md` | The same data as a readable table plus per-asset averages. |

Color rule: Green = SPY up and TLT up, Orange = SPY up and TLT down, Blue = SPY down and
TLT up, Red = both down; zero counts as up. Emergency meetings are excluded. Percent
values throughout. Small samples: treat as tendencies, not rules.
